# 00. 비전 · 목표

## 프로젝트명
**AccessAI** — 청각장애인을 위한 한국어 수어(KSL) → 자연어 실시간 번역 플랫폼

---

## 1. 비전 (Vision)

> **"누구나 정확하게 통하는 수어 — 청각장애인의 일상에 가장 가까운 번역기"**

청각장애인이 자신의 의사를 비장애인에게 **정확하게 전달**할 수 있고, **누구나 쉽게 접근 가능한** 도구를 만든다. 통역사 없이도, 글로 적지 않고도, 자신이 가장 편한 언어(수어)로 표현하면 즉시 한국어 문장으로 변환되어 상대방에게 전달된다.

---

## 2. 핵심 가치 (Core Values)

이 프로젝트는 4가지 가치를 추구하되, **명확한 우선순위**를 둔다. 의사결정이 충돌할 때 상위 가치를 따른다.

### 🥇 1순위 — 접근성 (Accessibility)
누구든지 별도의 학습이나 설정 없이 즉시 사용할 수 있어야 한다.
- 직관적인 UI, 큰 자막, 명확한 색상 대비
- 두 가지 입력 방식(웹캠 / 텍스트)으로 다양한 사용자 수용
- 별도 계정·로그인 없이 즉시 사용

### 🥇 1순위 — 정확도 (Accuracy)
잘못된 번역은 차라리 없는 것만 못하다.
- 수어 100개 단어 인식 정확도 70% 이상
- 동음이의어·유사 동작은 후보 목록 + 시각 자료로 사용자 선택
- LLM이 단어 시퀀스를 자연스러운 문장으로 정교하게 변환

### 🥈 2순위 — 신박한 기술 (Innovative Technology)
포트폴리오 가치를 위해 기술적 차별점을 명확히 한다.
- LLM + 컴퓨터 비전 결합 (Gemini API + MediaPipe + LSTM)
- 한국어 수어(KSL) 특화 — 영어 ASL 위주 생태계에서 차별화
- 국립국어원 + Wikipedia API 멀티소스 연동

### 🥈 2순위 — 실시간 소통 속도 (Real-time Speed)
접근성과 정확도를 해치지 않는 선에서 최대한 빠르게.
- 웹캠 입력 → 자연어 출력 2초 이내
- 텍스트 입력 → 수어 후보 표시 1초 이내

---

## 3. 타겟 사용자

### 주 사용자
**청각장애인 본인** — 자신의 의사를 비장애인에게 전달하고자 하는 상황

### 보조 사용자
**수어를 모르는 일반인** — 청각장애인의 수어를 이해하고자 하는 상황 (가족, 공공기관 직원, 의료진 등)

---

## 4. 사용 맥락

특정 상황에 한정되지 않은 **범용 소통 도구**로 설계한다.

- 일상 소통 (가족, 친구, 카페, 마트 등)
- 공공기관 (병원, 관공서, 은행)
- 교육 현장 (학교, 학원, 강의실)
- 긴급 상황 (즉각적 의사 전달이 필요한 모든 순간)

---

## 5. 목표 (Goals)

### 5.1 기능적 목표
- 한국어 수어 100개 단어 인식 정확도 70% 이상 달성
- 웹캠 입력 → 자연어 출력 평균 지연 2초 이내
- 두 가지 입력 방식(웹캠 / 텍스트) 모두 안정적 동작
- 동음이의어·유사 동작 수어를 시각적으로 구분 가능

### 5.2 기술적 목표
- LLM API와 컴퓨터 비전 기술의 효과적 결합
- 풀스택 구현 (React + FastAPI + AI API)
- 웹 → 모바일 앱 순차 개발

### 5.3 사회적 목표
- 청각장애인 약 40만 명의 일상 소통 장벽 완화
- 한국어 수어(KSL) 디지털 도구의 오픈소스 생태계 기여

---

## 6. 성공 기준 (Success Criteria)

| 지표 | 목표 |
|------|------|
| 수어 인식 정확도 | 70% 이상 |
| 실시간 처리 지연 | 2초 이내 |
| 지원 단어 수 | 100개 이상 |
| 입력 방식 | 2가지 (웹캠 + 텍스트) |
| 배포 | 웹 앱 배포 완료 + 모바일 앱 기본 UI |

---

## 7. 비전을 벗어나는 영역 (Non-Goals)

명확한 범위 설정을 위해 **이 프로젝트가 하지 않을 것**을 명시한다.

- ❌ 음성 → 수어 변환 (역방향)
- ❌ 한국어 외 다른 언어 수어 지원
- ❌ 수어 학습 교육 콘텐츠 제공
- ❌ 전문 통역사를 대체하는 수준의 정밀 번역

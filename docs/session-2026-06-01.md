### 2. 텍스트 입력 모드 — 문장 인식 불가 문제

**발견한 문제:**  
텍스트 입력 페이지(`TextInputPage.jsx`)에서 문장을 입력하면 수어 후보가 전혀 나오지 않음.

**원인:**  
KCISA 수어 사전 검색 로직(`sign_dictionary.py:56`)이 단어 단위 부분 일치 검색만 지원.  
```python
results = [item for item in _cache if word_lower in item["word"].lower()]
```
"오늘 날씨가 좋다" 같은 문장을 통째로 검색하면 사전 항목과 매칭되지 않아 결과 없음.

**결론:** 정상 동작. 원래 스펙이 단어 단위 검색으로 설계됨.

### 4. 제안된 해결 방향 (미구현, 논의만)

**"문장 입력 모드" 추가 구현 방안:**

```
사용자 입력: "오늘 병원에 가야 해"
  ↓ Gemini가 KSL 핵심 어휘 추출
["오늘", "병원", "가다"]
  ↓ 각 단어를 KCISA 사전에서 자동 검색
수어 카드 3개가 순서대로 표시됨
```

필요한 작업:
- 백엔드: `/dictionary/sentence` 엔드포인트 추가 (Gemini로 형태소 추출 → 단어별 사전 검색)

Gemini API 이미 연결되어 있어 추가 비용 없이 구현 가능.

### 6. sldict.korean.go.kr 미디어 접근 문제 — 집에서 확인 필요

**증상:** KCISA API가 반환하는 수어 영상/이미지 URL이 모두 `sldict.korean.go.kr` 도메인.  
학교 와이파이에서 해당 도메인 자체가 연결 안 됨 (타임아웃).

**다음 대화 시작 시 할 일:**  
집 네트워크(또는 핫스팟)에서 아래 URL을 브라우저에서 직접 열어볼 것:
```
http://sldict.korean.go.kr/multimedia/multimedia_files/convert/20191028/632066/MOV000253800_700X466.mp4
```
- **열리면** → 학교 와이파이가 막은 것. 코드 문제 없음.
- **안 열리면** → 서버 자체가 외부 임베딩 차단. 백엔드 프록시 또는 대안 검토 필요.

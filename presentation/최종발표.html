04 · 기술 선택 이유 (ADR)

왜 이 기술을 선택했는가?

🔧 FastAPI (ADR-0003)
  • Gemini SDK Python 완전 호환 — AI API 가장 안정적 연동
  • async/await 기본 지원 — 외부 API 3개 동시 호출, 응답 속도↑
  • Swagger 자동 문서화 — /docs 엔드포인트 즉시 확인
  • Django(무거운 구조), Flask(비동기 미지원) 검토 후 미채택
⚛️ useState + Context API (ADR-0002)
  • 전역 공유 상태 = 인증 1가지 — Redux는 오버엔지니어링
  • 외부 패키지 불필요 — React 내장, 번들 크기 최소화
  • useAuth() 커스텀 훅 — 모든 컴포넌트에서 로그인 상태 접근
  • Redux Toolkit, Zustand 검토 후 미채택
✨ Gemini Vision API 시행착오
  • 원래 계획: MediaPipe Hands + LSTM 수어 분류 모델
  • 문제: 한국어 KSL 학습 데이터 부족, 6주 내 학습 불가
  • 전환 결정: Gemini Vision API — 3초마다 프레임 분석
  • 결과: 웹캠 실시간 번역 기능 완성

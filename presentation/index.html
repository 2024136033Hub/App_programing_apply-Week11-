03 · 기술 선택 이유

왜 이 기술을 선택했는가?

⚛️ React + Vite + Tailwind
  • React — 컴포넌트 재사용·상태 관리, 수어 후보 카드 반복 UI에 최적
  • Vite — CRA 대비 개발 서버 속도 10배↑, 즉각적인 HMR
  • Tailwind — 유틸리티 클래스로 일관된 접근성 UI 팔레트 유지
🔧 FastAPI (Python)
  • Python 생태계 — MediaPipe·PyTorch 등 AI/ML 라이브러리와 동일 언어
  • 비동기 지원 — async/await로 여러 외부 API 동시 호출 → 응답 속도↑
  • 자동 문서화 — Swagger UI 자동 생성으로 개발·테스트 효율화
✨ Gemini API
  • LLM 필요 — 수어는 조사·어미 생략, 단순 나열로는 자연어 문장 불가
  • 한국어 품질 — 한국어 자연어 생성 성능 우수
  • 비용 — 무료 티어 제공, GPT 대비 접근성 우수
👁️ MediaPipe + LSTM
  • MediaPipe — Google 제공 실시간 손 랜드마크 21점 추출, 브라우저·Python 모두 지원
  • LSTM — 수어는 시간적 움직임 시퀀스 → CNN보다 시계열 패턴 학습에 유리
🏛️ 통합수어정보 API
  • 공식 데이터 — 문화체육관광부 제공, 15,000개↑ 단어
  • 풍부한 필드 — 동의어·카테고리·수어 설명 포함
  • 합법적 사용 — 공개 API, 별도 크롤링 불필요
📖 Wikipedia API
  • 직관적 이해 — 수어 단어 뜻을 이미지로 시각화, 청각장애인 접근성↑
  • 무료·빠른 응답 — 별도 이미지 DB 구축 불필요
